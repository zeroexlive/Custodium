# HMAC Signing — Test Vectors

Status: Phase 11 (2026-11-12). These vectors are generated by
the production signer (`waas/security/hmac/signing.py`) and are
**verified by the test suite**
(`tests/integration/test_hmac_vectors.py`) — if the canonical
scheme ever changes, the test and this document change together.

Canonical string (newline-joined, no trailing newline):

```text
<METHOD>
<path-with-query>
<timestamp>
<nonce>
<sha256-hex of raw body>
```

Signature: `HMAC-SHA256(secret, canonical)` hex.
